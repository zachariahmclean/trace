# Extract traces

Extract the raw trace from a list of fragments objects

## Usage

``` r
extract_trace_table(fragments_list)
```

## Arguments

- fragments_list:

  a list of fragments objects

## Value

A dataframe of the raw trace data. Each row representing a single scan.
