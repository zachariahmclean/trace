# Extract ladder summary

Extract a table summarizing the ladder models

## Usage

``` r
extract_ladder_summary(fragments_list, sort = FALSE)
```

## Arguments

- fragments_list:

  a list of fragments trace objects

- sort:

  A logical statement for if the samples should be ordered by average
  ladder R-squared.

## Value

a dataframe of ladder quality information

## Details

The ladder peaks are assigned using a custom algorithm that maximizes
the fit of detected ladder peaks and given base-pair sizes. This
function summarizes the R-squared values of these individual
correlations.
